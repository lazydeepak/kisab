# Kisab v0.2.0 Pilot Checklist

Operational checklist for the M4-04 guided farmer pilot against the private pilot candidate `0.2.0-pilot.1` (versionCode 2). One session record per device/user/scenario; per-task observations capture timing, confusion, category gaps, backup discoverability, and defect severity. Results feed the M4 exit gate and the terminology glossary. The published `v0.1.0` build remains the released product; `V0.1.0_PILOT_CHECKLIST.md` is the historical source checklist.

> **Data warning:** Do **not** use irreplaceable real farm data during early pilot validation unless a verified backup already exists. Use disposable, clearly labeled sample data until a verified backup of the device's current farm has been exported and confirmed restorable.
