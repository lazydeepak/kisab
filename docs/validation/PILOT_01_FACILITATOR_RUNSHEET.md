# PILOT-01 Facilitator Runbook — v0.2.2 (one page)

Companion to `PILOT_01_PROTOCOL_v0.2.2.md`. This is operations only; the protocol owns rules.

## Before the first session (once)

1. Device `ZA22374XPC` holds production-signed **v0.2.2 (code 5)** — verify Settings → About shows **Kisab 0.2.2**.
2. Print or open: this runbook + protocol + one copy of `PILOT_01_SESSION_TEMPLATE.md` per participant (P01…).
3. Quiet room; device charged; screen brightness comfortable.

## Before EACH participant (~5 minutes)

1. **Reset to clean start** (protocol §4a):
   - More → Farms → open every farm listed → DELETE FARM (confirm each) until first-run "Farm name" screen returns.
   - Settings → restore defaults: language per session matrix · text size default (**24 sp**) · appearance Follow-system.
   - If anything looks off: uninstall Kisab → reinstall the same APK from GitHub release v0.2.2 → allow install-unknown-apps when asked.
   - **⚠ Device hazard (ZA22374XPC): Android auto-restore can resurrect deleted farms and old settings after a reinstall.** After ANY reinstall, verify the first-run screen; if old farms reappear, delete them via the UI before the session. Factory-default text size is **24 sp** — do not "correct" it to 16.
2. Verify first-run screen + About version. Record reset method in template §1.
3. Read consent script; get agreement.

## During the session

- Follow task order T1→T16 (protocol §5). State goals exactly as written; **never name buttons/screens**; never explain terms before the comprehension probe.
- Let them struggle productively; intervene only at give-up or data-danger. Log EVERY intervention.
- Keyboard covering a SAVE button is expected — observe their recovery; press Back yourself only if they abandon.
- T14/T15 are mandatory for every participant. Do not hint that anything is missing.
- Note verbatim quotes with task numbers.

## After EACH participant (~10 minutes)

1. Complete the session file same day while memory is fresh (`PILOT_01_SESSION_P0X.md`), separating Observed fact / Interpretation / Recommendation.
2. Export nothing participant-owned; the session farm is disposable by design (consent covers deletion).
3. Perform the reset procedure again and verify clean state for the next participant.

## Stop conditions (protocol §14 / directive §14)

Stop the affected session immediately only for: data loss, accounting corruption, unrecoverable crash, security/privacy problem, destructive action without intended confirmation. Document and hold the baseline; do not hotfix silently.

## After the round

Deliver all completed `PILOT_01_SESSION_P0X.md` files for aggregation into `PILOT_01_RESULTS_v0.2.2.md` (task-success matrix, repeated patterns, terminology dispositions, generic-cash verdict, ranked M15 candidates). Minimum three sessions for analysis.
